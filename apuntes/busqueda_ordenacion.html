Tema 1

Conceptos generales

Las estructuras de datos se representan de dos formas básicas: con vectores o con memoria dinámica. Para la segunda hacen falta los punteros.

El puntero

Puntero: variable que almacena una dirección de memoria. Se dice que "apunta" a esa zona de memoria.

Al declararlo se indica su nombre y su tipo asociado, que determina a qué tipo de elementos podrá apuntar:

P puntero a enteros

P puede apuntar tanto a variables estáticas como a variables dinámicas de ese tipo.

Variable estática

Su memoria se solicita en tiempo de compilación. Tiene nombre.

Variable dinámica

Su memoria se solicita en tiempo de ejecución. No tiene nombre: solo se accede a ella mediante un puntero que apunte a su zona de memoria.

El valor NULO

Valor especial que se asigna a un puntero para indicar que no apunta a ninguna dirección de memoria válida.

P ← NULO

Reservar y liberar memoria

1
Reservar. RESERVAR_MEMORIA recibe el tamaño del bloque que se pide y devuelve la dirección de comienzo del bloque asignado, o NULO si la solicitud no tuvo éxito. El tamaño lo calcula la función tamaño(T), que da el espacio que necesita un dato del tipo T.
2
Comprobar. Antes de usar la memoria conviene comprobar que la reserva funcionó: operar sobre memoria no asignada provoca un error en el programa.
3
Liberar. Cuando la variable dinámica ya no hace falta, LIBERAR(P) devuelve al sistema la memoria a la que apunta P.
P ← RESERVAR_MEMORIA(tamaño(entero))

Si (P = NULO) entonces
   ESCRIBIR "error en la reserva de memoria"
   ACABAR   ** u otra operación
fin-si

LIBERAR(P)
Idea clave: reservar → comprobar si es NULO → usar → liberar.

Operaciones básicas

Búsqueda

Determinar si un valor aparece en la tabla. El resultado puede indicar si hubo éxito, si aparece varias veces, en qué posición o posiciones…

Ordenación

Reorganizar los elementos según un criterio, de forma ascendente o descendente.
Tema 2 · Búsqueda

Algoritmos de búsqueda

Se busca un valor X en un vector V de tamaño N y tipo T, que puede tener valores repetidos.

Si el vector no está lleno, los módulos reciben como segundo parámetro el número de elementos realmente almacenados. Se supone que estos ocupan posiciones consecutivas desde la primera.

Búsqueda lineal (secuencial)

Vectores desordenadosVectores ordenados

Se recorre el vector de un extremo al opuesto hasta encontrar una componente igual a X o hasta haber recorrido todo el vector, lo que ocurra primero. En el segundo caso se indica que X no está.

  • Si X aparece varias veces, se encuentra el que tenga el índice más próximo al extremo donde empieza el recorrido.
  • Si el vector está ordenado ascendentemente, la búsqueda puede terminar al encontrar un valor mayor que X: X ya no puede aparecer. Se sale del bucle al encontrar un valor ≥ X o al llegar al último elemento, y hay éxito si el valor donde se detuvo es igual a X.

Ejemplo: buscar X = 14 en (15, 18, 7, 75, 14, 13, 43, 40)

Búsqueda binaria (dicotómica)

Solo vectores ordenados

Con los datos en orden creciente, se compara X con la componente central:

¿V(CEN) = X?encontrado
¿V(CEN) > X?seguir en la mitad izquierda
DER ← CEN−1
¿V(CEN) < X?seguir en la mitad derecha
IZQ ← CEN+1

Se repite sobre la mitad elegida hasta encontrar el valor o hasta que el intervalo de búsqueda se anule. En cada paso el intervalo se reduce aproximadamente a la mitad.

Si X está repetido, se obtiene uno de ellos (los repetidos son consecutivos), no necesariamente el primero.

Tema 2 · Ordenación

Algoritmos de ordenación

Ascendente (creciente)

Valores menores al principio y mayores al final.

Descendente (decreciente)

Valores mayores al principio y menores al final.
  • Los valores repetidos quedan en posiciones consecutivas.
  • Los valores alfanuméricos se ordenan por orden lexicográfico.
  • Si cada componente guarda datos compuestos (nombre, edad, DNI…), se ordena por alguno de esos datos.
En todos los métodos se ordenan los N elementos de un vector V de forma ascendente. Todos los ejemplos usan el mismo vector: (15, 18, 7, 75, 14, 13, 43, 40).
Para ordenar de forma descendente basta con invertir las comparaciones. Por ejemplo, en la burbuja se intercambia si V(I) < V(I+1) en lugar de V(I) > V(I+1).

Inserción directa

También llamado método de la baraja

Se toma cada elemento y se coloca en su sitio respecto a los que tiene a su izquierda, que ya están ordenados entre sí, igual que al ordenar las cartas de una mano.

Para cada elemento desde el segundo hasta el último:

Se copia el valor actual en una variable auxiliar (AUX).
2
Desde el elemento anterior hasta el primero, se desplazan un lugar a la derecha todos los que sean mayores que AUX, para dejar un hueco.
3
Se coloca AUX en el hueco.

Intercambio directo

También llamado método de la burbuja

Se recorre el vector varias veces comparando elementos consecutivos e intercambiándolos si están mal colocados.

Izquierda → derecha

Los valores mayores se desplazan hacia la derecha. Cada pasada deja uno en su sitio en el extremo derecho de la zona.

Derecha → izquierda

Los valores menores se desplazan hacia la izquierda. Cada pasada deja uno en su sitio en el extremo izquierdo de la zona.

Cada pasada deja un elemento en su posición definitiva en el extremo de la zona comparada, así que en la siguiente pasada ese elemento se excluye. Se hacen N−1 iteraciones.

Sacudida con test

Igual que en la burbuja, se puede parar si en una pasada, ya sea de izquierda a derecha o de derecha a izquierda, se comprueba que todos los elementos están ordenados, es decir, que no hubo intercambios.

Sacudida con salto

Descarta varias posiciones de los extremos de una vez, en lugar de solo una:

  • Pasada derecha → izquierda: si el último intercambio afecta a X y X+1, las posiciones 1..X ya están ordenadas.

Shell

También llamado inserción con incrementos decrecientes

Es una mejora de la inserción directa. Primero ordena por inserción los elementos separados S1 posiciones, después los separados S2 < S1, y así sucesivamente hasta llegar a distancia 1. Los valores S1, S2… se llaman incrementos.

1

2

3

En los apuntes, la distancia inicial es la mitad del número de elementos y en cada iteración se divide entre 2 (división entera), hasta llegar a 1. Con N = 8 las distancias son 4 → 2 → 1.

QuickSort

Ordenación rápida · técnica "divide y vencerás"

Se elige un valor llamado pivote. Los elementos menores se llevan a su izquierda y los mayores a su derecha. Después se aplica lo mismo a cada una de las dos partes, de forma recursiva, hasta que todas las particiones tengan tamaño 1.

1
Se elige un elemento como pivote.
2
Si el vector tiene tamaño 1, ya está ordenado. Si no, se divide en V1 y V2, de forma que los elementos de V1 sean menores (o iguales, si hay repetidos) que los de V2.
3
Se ordenan V1 y V2 aplicando QuickSort.
4
Se concatenan V1 y V2 y se obtiene V ordenado.
El pivote: en principio puede ser cualquier valor, pero una mala elección reduce mucho la eficiencia. En los apuntes se toma el valor de la posición central del vector o subvector: V((IZQ+DER)\2).

MergeSort

Ordenación por mezcla · técnica "divide y vencerás"

1
Se divide el vector en dos mitades.
2
Se ordena cada mitad aplicando MergeSort.
3
Se mezclan las dos mitades y se obtiene un vector ordenado.

La división se aplica recursivamente. Una partición de un solo elemento se considera ordenada. Después se mezclan particiones de 1 para formar particiones ordenadas de 2, luego de 4… hasta tener todo el vector ordenado.

La operación de mezcla

Une dos vectores ordenados en uno nuevo que contiene todos sus elementos y conserva el orden. Aquí los dos "vectores" son en realidad dos tramos del vector original: IZQ..CEN y CEN+1..DER.

  • Se compara un elemento de cada tramo, empezando por los primeros, y se copia el menor en el destino.
  • Se avanza en el tramo del que se acaba de copiar y se sigue comparando.
  • Cuando se han copiado todos los elementos de un tramo, se copian los que quedan del otro.
  • El destino es un vector auxiliar TEMP. Al acabar, se copian en V las posiciones IZQ..DER de TEMP.

Tema 2 · Búsqueda y ordenación externa

Ficheros secuenciales

La búsqueda y ordenación externa trabaja con datos guardados en ficheros, en memoria secundaria (disco), en lugar de en vectores en memoria principal.

Fichero, registro, campo y clave

Fichero o archivo: conjunto de informaciones estructuradas en unidades de acceso llamadas registros, todos del mismo tipo, guardadas en algún soporte de memoria secundaria.
TérminoSignificado
RegistroEstructura formada por uno o más campos, que pueden ser de tipos diferentes y tener a su vez subcampos.
Clave (identificativo)Campo especial que identifica al registro o sirve de criterio para las operaciones. Puede ser única o repetirse. Si hay varias, se habla de clave primaria, secundaria…
AccesoProcedimiento para situarse sobre un registro concreto y leerlo o escribirlo.
Acceso secuencial: los registros se recorren en el orden en que están guardados, de uno en uno desde el primero. Para llegar al registro n hay que pasar por los n−1 anteriores. No se puede saltar directamente al registro central, así que no se puede aplicar búsqueda binaria.

Operaciones básicas

Son cinco: apertura, cierre, lectura, escritura y comprobación de fin de fichero. La primera siempre es la apertura y la última el cierre.

Nombre físico

El del archivo en disco (NOMBRE_F, una cadena que puede incluir la ruta).

Nombre lógico

El que usa el programa (F). Se asocia al físico en la apertura, y desde ahí todas las operaciones usan el nombre lógico.

Para leer y escribir se usa una variable del mismo tipo que los registros, el registro buffer (REG_BUFFER), que intercambia registros entre el fichero y el programa.

Modos de apertura

EscrituraPara escribir borrando lo que hubiera. El puntero se coloca al comienzo.Se crea
AñadirPara escribir conservando el contenido. Se escribe a partir del final.—

F ← Abrir NOMBRE_F para escritura

1
Leer F, REG_BUFFER: copia en el buffer el registro al que apunta el puntero de lectura y avanza el puntero al siguiente.
2
Escribir F, REG_BUFFER: coloca el contenido del buffer donde indica el puntero de escritura y lo avanza.
3
FF(F): función lógica que vale Verdadero si el puntero de lectura está en la marca de fin de fichero, es decir, si no quedan registros por leer.
4
Cerrar F: libera el fichero para otros programas. Si estaba abierto para escritura, el cierre escribe la marca de fin de fichero.
Ojo: antes de cada lectura hay que comprobar FF(F). Leer cuando ya no quedan registros provoca un error.
Tema 2 · Ordenación externa

Ordenación externa

Un fichero está clasificado (ordenado) de forma ascendente o descendente si todos sus registros están en ese orden según un campo, la clave de ordenación.

Primera pregunta: si el fichero cabe en memoria principal, lo mejor es cargarlo en un vector, aplicar un método de ordenación interna y copiar los datos ordenados al fichero. Solo si no cabe se usa ordenación externa.

Los métodos de ordenación externa se basan en particiones y mezclas (fusiones):

Partición

Genera dos o más ficheros a partir de uno.

Mezcla o fusión

Combina ficheros ordenados, o parcialmente ordenados, en uno que mantiene el orden.

Ambas operaciones necesitan ficheros auxiliares y muchos accesos a disco. Cuantos más accesos a disco, más lento es el método.

Los ejemplos usan el fichero de los apuntes, con estas claves: 15 18 7 75 14 13 43 40 51 93 75 26 64 27 13. Cada número representa la clave del registro; al mover la clave se mueve el registro entero.

Mezcla natural

También hace particiones y mezclas, pero aprovecha el orden que ya existe en los datos: trabaja con tramos ya ordenados de longitud variable.

1
Separar: copia el primer tramo ordenado de F en F1, el segundo en F2, el tercero en F1… alternando hasta acabar el fichero.
2
Mezclar: fusiona sobre F cada tramo de F1 con un tramo de F2 y forma uno ordenado más largo. L cuenta cuántos tramos se han formado.

Trampas típicas de examen

Búsqueda binaria solo si el vector está ordenado por el campo que se busca. Un vector de alumnos ordenado por DNI no permite buscar una nota con búsqueda binaria: hay que usar la lineal.
Burbuja con test: hace falta una pasada completa sin intercambios. No basta con que una comparación no intercambie.
Inserción (directa o binaria): la zona izquierda está ordenada, pero no es definitiva.
QuickSort: no divide en mitades iguales; eso lo hace MergeSort. El pivote sí influye en la eficiencia.
Burbuja izquierda → derecha lleva los mayores hacia el final; la de derecha → izquierda lleva los menores hacia el principio.
Orden descendente: se invierte la comparación. En la burbuja se intercambia si la primera es menor que la segunda.
Búsqueda lineal: funciona con cualquier tipo de dato y con vectores ordenados o no. Si hay repetidos, encuentra el más cercano al punto de inicio.
Shell se basa en la inserción y la sacudida en la burbuja. ¡No los confundas!
Mezcla directa no aprovecha el orden previo: sus iteraciones dependen solo del número de registros. La mezcla natural sí lo aprovecha: dependen del desorden.
Raíz hace partición y concatenación, no mezcla, y solo sirve con claves enteras.
Ficheros secuenciales: nada de búsqueda binaria. Y si el fichero cabe en memoria, es mejor cargarlo y usar ordenación interna.
Mezcla natural en orden descendente: un tramo termina cuando se lee un valor mayor que el anterior, no menor.

int suma(const int *v, int n)

int busqueda_lineal(const int v[], int n, int x)
{
    int i = 0;
    while (v[i] != x && i < n - 1) {
        i++;
    }
    if (v[i] == x) {
        return i;
    }
    return -1;
}

void insercion_directa(int v[], int n, int *comp, int *desp)
{
    *comp = 0;
    *desp = 0;
    for (int i = 1; i < n; i++) {
        int aux = v[i];

        while (j > 0 && seguir) {

            }

        mostrar_vector(v, n);

Objetivo: manejar los modos de apertura y aplicar la regla de los apuntes: si el fichero cabe en memoria, se carga en un vector, se ordena con un método interno y se vuelve a guardar.

  1. Abre en modo "r" un fichero que no existe y comprueba que detectas el error (fopen devuelve NULL).
  2. Crea datos.txt con "w" y escribe con fprintf, uno por línea: 42 7 30 3 50 18 25 12 34 21.
  3. Ábrelo con "a" y añade el 15. Ábrelo con un editor y comprueba que no se ha borrado nada. Prueba también con "w" para ver la diferencia.
  4. Escribe int cargar(const char *nombre, int v[], int max): lee los números con fscanf hasta que falle y devuelve cuántos ha leído.
  5. Ordena el vector con tu inserción directa y guárdalo en ordenados.txt con void guardar(const char *nombre, const int v[], int n).
Abrir no_existe.txt: error detectado
Leidos 11: 42 7 30 3 50 18 25 12 34 21 15
Ordenados: 3 7 12 15 18 21 25 30 34 42 50
Guardado en ordenados.txt
Debe cumplir: cada fopen se comprueba y cada fichero abierto se cierra. No uses while (!feof(f)): controla el valor que devuelve fscanf.
Pistaint n = 0, x; while (n < max && fscanf(f, "%d", &x) == 1) v[n++] = x;. fscanf devuelve cuántos datos ha leído bien, así que con un %d debe devolver 1.
Solución

Inténtalo antes de abrirla. Hay muchas formas correctas: esta sigue el pseudocódigo de los apuntes y compila con gcc -Wall -Wextra sin avisos.

#include <stdio.h>

#define MAX 100

/* lee enteros del fichero hasta que fscanf falle; devuelve cuántos ha leído */
int cargar(const char *nombre, int v[], int max)
{
    FILE *f = fopen(nombre, "r");
    if (f == NULL) {
        return -1;
    }
    int n = 0, x;
    while (n < max && fscanf(f, "%d", &x) == 1) {
        v[n] = x;
        n++;
    }
    fclose(f);
    return n;
}

void guardar(const char *nombre, const int v[], int n)
{
    FILE *f = fopen(nombre, "w");
    if (f == NULL) {
        printf("No se pudo crear %s\n", nombre);
        return;
    }
    for (int i = 0; i < n; i++) {
        fprintf(f, "%d\n", v[i]);
    }
    fclose(f);
}

void insercion_directa(int v[], int n)
{
    for (int i = 1; i < n; i++) {
        int aux = v[i];
        int j = i;
        while (j > 0 && v[j - 1] > aux) {
            v[j] = v[j - 1];
            j--;
        }
        v[j] = aux;
    }
}

void mostrar_vector(const int v[], int n)
{
    for (int i = 0; i < n; i++) {
        printf(" %d", v[i]);
    }
    printf("\n");
}

int main(void)
{
    /* 1. abrir en lectura un fichero que no existe */
    FILE *f = fopen("no_existe.txt", "r");
    if (f == NULL) {
        printf("Abrir no_existe.txt: error detectado\n");
    } else {
        fclose(f);
    }

    /* 2. crear datos.txt con "w" */
    int datos[10] = {42, 7, 30, 3, 50, 18, 25, 12, 34, 21};
    guardar("datos.txt", datos, 10);

    /* 3. añadir el 15 con "a" (no borra lo anterior) */
    f = fopen("datos.txt", "a");
    if (f == NULL) {
        return 1;
    }
    fprintf(f, "%d\n", 15);
    fclose(f);

    /* 4. cargar en un vector */
    int v[MAX];
    int n = cargar("datos.txt", v, MAX);
    if (n < 0) {
        printf("No se pudo abrir datos.txt\n");
        return 1;
    }
    printf("Leidos %d:", n);
    mostrar_vector(v, n);

    /* 5. ordenar en memoria y guardar */
    insercion_directa(v, n);
    printf("Ordenados:");
    mostrar_vector(v, n);
    guardar("ordenados.txt", v, n);
    printf("Guardado en ordenados.txt\n");
    return 0;
}

Solución

Inténtalo antes de abrirla. Hay muchas formas correctas: esta sigue el pseudocódigo de los apuntes y compila con gcc -Wall -Wextra sin avisos.

#include <stdio.h>
#include <string.h>

typedef struct {
    char titulo[80];
    char autor[50];
    int anioPublicacion;
    char prestado[3];      /* "Si" o "No" */
    double precio;
} Libro;

void mostrar_libro(int i, Libro L)
{
    printf("%d. %s | %s | %d | %s | %.2f\n",
           i, L.titulo, L.autor, L.anioPublicacion, L.prestado, L.precio);
}

/* búsqueda lineal en el fichero: 1 si lo encuentra (y lo copia), 0 si no */
int buscar_titulo(const char *fichero, const char *titulo, Libro *resultado)
{
    FILE *f = fopen(fichero, "rb");
    if (f == NULL) {
        return 0;
    }
    Libro L;
    while (fread(&L, sizeof(Libro), 1, f) == 1) {
        if (strcmp(L.titulo, titulo) == 0) {
            *resultado = L;
            fclose(f);
            return 1;
        }
    }
    fclose(f);
    return 0;
}

/* filtrado: recorre todo el fichero */
void listar_por_estado(const char *fichero, const char *estado)
{
    FILE *f = fopen(fichero, "rb");
    if (f == NULL) {
        return;
    }
    Libro L;
    while (fread(&L, sizeof(Libro), 1, f) == 1) {
        if (strcmp(L.prestado, estado) == 0) {
            printf("  %s | %s\n", L.titulo, L.autor);
        }
    }
    fclose(f);
}

int contar(const char *fichero)
{
    FILE *f = fopen(fichero, "rb");
    if (f == NULL) {
        return 0;
    }
    Libro L;
    int c = 0;
    while (fread(&L, sizeof(Libro), 1, f) == 1) {
        c++;
    }
    fclose(f);
    return c;
}

int main(void)
{
    Libro libros[6] = {
        {"Estructuras de Datos", "Mark Allen Weiss", 2007, "No", 45.90},
        {"Introduccion a Algoritmos", "Thomas H. Cormen", 2009, "Si", 89.00},
        {"Programacion en C Moderna", "J. Doe", 2021, "No", 39.95},
        {"Sistemas Operativos", "Andrew S. Tanenbaum", 2015, "No", 59.50},
        {"Fundamentos de Bases de Datos", "Hector Garcia-Molina", 2014, "Si", 72.00},
        {"Inteligencia Artificial", "Stuart Russell", 2016, "No", 70.80}
    };

    /* 1. escribir en binario */
    FILE *f = fopen("libros.bin", "wb");
    if (f == NULL) {
        printf("No se pudo crear libros.bin\n");
        return 1;
    }
    for (int i = 0; i < 6; i++) {
        fwrite(&libros[i], sizeof(Libro), 1, f);
    }
    fclose(f);

    /* 2. leer y listar */
    f = fopen("libros.bin", "rb");
    if (f == NULL) {
        return 1;
    }
    Libro L;
    int i = 1;
    while (fread(&L, sizeof(Libro), 1, f) == 1) {
        mostrar_libro(i, L);
        i++;
    }
    fclose(f);

    /* 3. buscar por título */
    char titulo[80];
    printf("Titulo a buscar: ");
    scanf(" %79[^\n]", titulo);
    Libro encontrado;
    if (buscar_titulo("libros.bin", titulo, &encontrado)) {
        printf("Encontrado: %s - %s - %.2f euros\n",
               encontrado.titulo, encontrado.autor, encontrado.precio);
    } else {
        printf("No encontrado\n");
    }

    /* 4. filtrar por préstamo */
    char estado[3];
    printf("Estado (Si/No): ");
    scanf("%2s", estado);
    listar_por_estado("libros.bin", estado);

    /* 5. ampliación: añadir con "ab" y contar */
    Libro nuevo = {"Algoritmos en C", "Robert Sedgewick", 1998, "No", 50.00};
    f = fopen("libros.bin", "ab");
    if (f != NULL) {
        fwrite(&nuevo, sizeof(Libro), 1, f);
        fclose(f);
    }
    printf("Registros en el fichero: %d\n", contar("libros.bin"));
    return 0;
}

Ordenar y buscar

Tipo examen3 funcionesordenación + búsqueda binaria

Enunciado: dado el vector desordenado int v[10] = {42, 7, 30, 3, 50, 18, 25, 12, 34, 21};, escribe un programa que lo ordene de menor a mayor y busque en él un valor introducido por el usuario.

El programa debe tener exactamente estas tres funciones además de main:

  • void mostrar_vector(const int v[], int n)
  • void ordenar(int v[], int n): selección directa o inserción directa, siguiendo el pseudocódigo de los apuntes.
  • int busqueda_binaria(const int v[], int n, int x): devuelve el índice o −1.

main muestra el vector original, lo ordena, lo muestra ordenado, pide un valor y dice en qué posición del vector ordenado está.

Vector original: 42 7 30 3 50 18 25 12 34 21
Vector ordenado: 3 7 12 18 21 25 30 34 42 50
Valor a buscar: 18
18 esta en la posicion 3 del vector ordenado
---
Valor a buscar: 19
19 no esta en el vector
Prueba esto: llama a busqueda_binaria sobre el vector antes de ordenarlo buscando 18. Devuelve −1 aunque el 18 está, porque la búsqueda binaria solo funciona con datos ordenados. Explícalo con un comentario en el código.
ComprobacionesCon el vector ordenado: 3 → 0, 18 → 3, 42 → 8, 50 → 9, 19 → −1. Si 3 o 50 no aparecen, revisa los extremos (der = n − 1). Si te piden mostrar la posición "como en los apuntes", suma 1 al índice.
Solución

Inténtalo antes de abrirla. Hay muchas formas correctas: esta sigue el pseudocódigo de los apuntes y compila con gcc -Wall -Wextra sin avisos.

#include <stdio.h>

void mostrar_vector(const int v[], int n)
{
    for (int i = 0; i < n; i++) {
        printf("%d ", v[i]);
    }
    printf("\n");
}

/* selección directa (pseudocódigo de los apuntes) */
void ordenar(int v[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        int aux = v[i];
        for (int j = i + 1; j < n; j++) {
            if (v[j] < aux) {
                k = j;
                aux = v[j];
            }
        }
        v[k] = v[i];
        v[i] = aux;
    }
}

/* búsqueda binaria: devuelve el índice o -1 */
int busqueda_binaria(const int v[], int n, int x)
{
    int izq = 0;
    int der = n - 1;
    int cen = (izq + der) / 2;

    while (v[cen] != x && izq < der) {
        if (v[cen] > x) {
            der = cen - 1;
        } else {
            izq = cen + 1;
        }
        cen = (izq + der) / 2;
    }
    if (v[cen] == x) {
        return cen;
    }
    return -1;
}

int main(void)
{
    int v[10] = {42, 7, 30, 3, 50, 18, 25, 12, 34, 21};
    int x;

    /* sin ordenar la búsqueda binaria NO funciona: aquí devolvería -1
       buscando 18 aunque esté, porque descarta mitades sin sentido */

    printf("Vector original: ");
    mostrar_vector(v, 10);

    ordenar(v, 10);
    printf("Vector ordenado: ");
    mostrar_vector(v, 10);

    printf("Valor a buscar: ");
    scanf("%d", &x);
    int pos = busqueda_binaria(v, 10, x);
    if (pos != -1) {
        printf("%d esta en la posicion %d del vector ordenado\n", x, pos);
    } else {
        printf("%d no esta en el vector\n", x);
    }
    return 0;
}

Ordenar en el sentido que elija el usuario y buscar

Tipo examenascendente / descendentebúsqueda binaria adaptada

Enunciado: genera un vector de 10 enteros aleatorios entre 1 y 100, pregunta al usuario si lo quiere ordenado de menor a mayor o de mayor a menor, ordénalo, muéstralo y busca un valor con búsqueda binaria.

  • void generar_vector(int v[], int n): números con rand() % 100 + 1. Llama a srand(time(NULL)) una vez en main.
  • void ordenar(int v[], int n, int ascendente): la función del ejercicio de ordenar en los dos sentidos.
  • int busqueda_binaria(const int v[], int n, int x, int ascendente): si el vector está en orden descendente, el recorte se invierte. Cuando el central es menor que x, x está a la izquierda.
  • Para comprobarlo sin aleatorios, prueba antes con el vector fijo {42, 7, 30, 3, 50, 18, 25, 12, 34, 21}.
Orden (1 = menor a mayor, 0 = mayor a menor): 0
Vector ordenado: 50 42 34 30 25 21 18 12 7 3
Valor a buscar: 18
18 esta en la posicion 6
Valor a buscar: 42
42 esta en la posicion 1
Para pensar: si usas la búsqueda binaria normal (la ascendente) sobre el vector descendente, buscando 18 devuelve −1. ¿Por qué? Porque al ver que el central es mayor que 18 descarta la mitad derecha, que es justo donde está.
PistaSolo cambia una línea: if (ascendente ? v[cen] > x : v[cen] < x) der = cen - 1; else izq = cen + 1;. Con el vector fijo en descendente: 50 → 0, 42 → 1, 18 → 6, 3 → 9, 19 → −1.
Solución

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define TAM 10

void generar_vector(int v[], int n)
{
    for (int i = 0; i < n; i++) {
        v[i] = rand() % 100 + 1;
    }
}

void mostrar_vector(const int v[], int n)
{
    for (int i = 0; i < n; i++) {
        printf("%d ", v[i]);
    }
    printf("\n");
}

/* inserción directa en el sentido indicado */
void ordenar(int v[], int n, int ascendente)
{
    for (int i = 1; i < n; i++) {
        int aux = v[i];
        int j = i;
        while (j > 0 && (ascendente ? v[j - 1] > aux : v[j - 1] < aux)) {
            v[j] = v[j - 1];
            j--;
        }
        v[j] = aux;
    }
}

/* binaria para los dos sentidos: en descendente se invierte el recorte */
int busqueda_binaria(const int v[], int n, int x, int ascendente)
{
    int izq = 0;
    int der = n - 1;
    int cen = (izq + der) / 2;

    while (v[cen] != x && izq < der) {
        if (ascendente ? v[cen] > x : v[cen] < x) {
            der = cen - 1;
        } else {
            izq = cen + 1;
        }
        cen = (izq + der) / 2;
    }
    if (v[cen] == x) {
        return cen;
    }
    return -1;
}

int main(void)
{
    int v[TAM];
    int asc, x;

    srand((unsigned)time(NULL));
    generar_vector(v, TAM);
    /* para probar sin aleatorios, usa en su lugar:
       int v[TAM] = {42, 7, 30, 3, 50, 18, 25, 12, 34, 21}; */

    printf("Vector generado: ");
    mostrar_vector(v, TAM);

    printf("Orden (1 = menor a mayor, 0 = mayor a menor): ");
    scanf("%d", &asc);
    ordenar(v, TAM, asc);
    printf("Vector ordenado: ");
    mostrar_vector(v, TAM);

    printf("Valor a buscar: ");
    scanf("%d", &x);
    int pos = busqueda_binaria(v, TAM, x, asc);
    if (pos != -1) {
        printf("%d esta en la posicion %d\n", x, pos);
    } else {
        printf("%d no esta en el vector\n", x);
    }
    return 0;
}

  • int buscar_alumno(const Alumno lista[], int n, int id): la del ejercicio de búsqueda en structs.
  • Guarda en main una variable ordenado (0/1). Si eligen la opción 3 sin haber ordenado antes, avisa en lugar de buscar.

PistaLa comparación cambia de v[j] < aux a lista[j].id < aux.id, y el intercambio final es lista[k] = lista[i]; lista[i] = aux;: se copian structs enteros. Buscando 33 debe decir que no existe.
Solución

Inténtalo antes de abrirla. Hay muchas formas correctas: esta sigue el pseudocódigo de los apuntes y compila con gcc -Wall -Wextra sin avisos.

#include <stdio.h>

typedef struct {
    int id;
    char nombre[30];
    float nota;
} Alumno;

void mostrar_alumnos(const Alumno lista[], int n)
{
    printf("ID   Nombre    Nota\n");
    for (int i = 0; i < n; i++) {
        printf("%-4d %-9s %.1f\n", lista[i].id, lista[i].nombre, lista[i].nota);
    }
}

/* selección directa por id: se mueve el struct completo */
void seleccion_directa(Alumno lista[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        Alumno aux = lista[i];
        for (int j = i + 1; j < n; j++) {
            if (lista[j].id < aux.id) {
                k = j;
                aux = lista[j];
            }
        }
        lista[k] = lista[i];
        lista[i] = aux;
    }
}

int buscar_alumno(const Alumno lista[], int n, int id)
{
    int izq = 0;
    int der = n - 1;
    int cen = (izq + der) / 2;

    while (lista[cen].id != id && izq < der) {
        if (lista[cen].id > id) {
            der = cen - 1;
        } else {
            izq = cen + 1;
        }
        cen = (izq + der) / 2;
    }
    if (lista[cen].id == id) {
        return cen;
    }
    return -1;
}

int main(void)
{
    Alumno lista[6] = {
        {31, "Carlos", 6.7f}, {10, "Ana", 7.5f},   {47, "Pablo", 5.5f},
        {20, "Maria", 8.2f},  {60, "Sofia", 9.5f}, {14, "Luis", 6.0f}
    };
    int n = 6;
    int ordenado = 0;      /* 1 cuando la lista está ordenada por id */
    int opcion, id;

    do {
        printf("\n1. Mostrar alumnos\n");
        printf("2. Ordenar alumnos por ID (seleccion directa)\n");
        printf("3. Buscar alumno por ID (busqueda binaria)\n");
        printf("0. Salir\n");
        printf("Opcion: ");
        scanf("%d", &opcion);

        switch (opcion) {
        case 1:
            mostrar_alumnos(lista, n);
            break;
        case 2:
            seleccion_directa(lista, n);
            ordenado = 1;
            mostrar_alumnos(lista, n);
            break;
        case 3:
            if (!ordenado) {
                printf("Primero hay que ordenar la lista por ID\n");
                break;
            }
            printf("ID a buscar: ");
            scanf("%d", &id);
            int pos = buscar_alumno(lista, n, id);
            if (pos != -1) {

                printf("No existe un alumno con ID %d\n", id);
            }
            break;
        case 0:
            printf("Adios\n");
            break;
        default:
            printf("Opcion no valida\n");
        }
    } while (opcion != 0);
